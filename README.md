# Бавись CRM

CRM для проєкту «Бавись» (ігрові програми та аніматори на святах). Адаптована зі структури
кейтеринг-CRM «Бавись клієнти.xlsx»: замовлення, клієнти, статуси, фінансові показники та
історія взаємодій, з бекендом на Node.js і дашбордом, що оновлюється в реальному часі.

## Структура

- `server/` — Express API + SQLite (better-sqlite3) + Socket.IO для realtime-оновлень
- `client/` — React + Vite дашборд (Recharts для графіків)

## Запуск (два термінали)

```bash
cd server
npm install
npm run seed   # одноразово: наповнює БД реальними даними з таблиці «Бавись клієнти.xlsx»
npm run dev    # API на http://localhost:4000
```

```bash
cd client
npm install
npm run dev    # дашборд на http://localhost:5173
```

## Дані

`npm run seed` імпортує 12 реальних замовлень (травень–серпень 2026) з рядків
`ПРОЕКТ = Ігри` таблиці «Бавись клієнти.xlsx» та 3 співробітників (Маряна, Ірина, Наталя).
Повторний запуск `npm run seed` додасть дублікати — щоб перезапустити з нуля, видаліть
`server/bavys.db*` перед повторним запуском.
